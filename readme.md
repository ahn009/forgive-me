🕊️ The Zohaib Protocol: A Digital Peace Treaty

This repository contains a bespoke, interactive experience designed specifically for Zohaib. It is a combination of generative AI, interactive physics, and creative code, built to serve as a sincere apology and a bridge to restoring a valued friendship.

🚀 Experience Features

Generative Apologies: Integrated with Google Gemini 2.5 Flash to create unique, poetic messages in real-time.

AI Voice Synthesis: Multi-speaker TTS (Text-to-Speech) capabilities to "read" the apology aloud.

Interactive Physics: A custom-built particle warp engine that reacts to scroll velocity and magnetic buttons that track user movement.

The Forgiveness Automation: A final-stage trigger that detects the user's device (Mobile vs. Desktop) and automates a WhatsApp unblock/forgiveness message.

🛠️ Deployment Instructions

To view this artifact live:

Ensure the file apology.html is renamed to index.html.

Host on GitHub Pages (Settings > Pages > Branch: Main).

Open the generated github.io link on a mobile device for the full interactive experience.
